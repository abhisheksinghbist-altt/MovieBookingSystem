# Movie Ticket Booking System

This is a C++ based Movie Ticket Booking System. It is made to make the process of booking movie tickets simple and easy.

The system allows users to:
- See the movies that are currently playing.
- See the shows available for a movie.
- Check the seat layout and availability.
- Book a movie ticket.
- Print the ticket details.
- Cancel a booking.
- Make the payment for the ticket.

## Technologies Used

- C++
- Object-Oriented Programming
- File Handling
- Visual Studio Code

## How to Run

Open the project in Visual Studio Code and compile the C++ files using a C++ compiler.

Then run the program and select an option from the menu.

## Main Menu

1. List Movies Currently Playing
2. List Shows for a Movie
3. Display Seat Layout
4. Book Ticket
5. Print Ticket
6. Cancel Booking
7. Exit

## Purpose of the Project

The purpose of this project is to create a simple movie ticket booking system and apply the C++ concepts learned during the course.
